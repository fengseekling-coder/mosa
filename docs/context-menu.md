# 右键菜单功能说明

MOSA 现已支持完整的右键菜单功能，为导航栏和素材库提供快捷操作入口。

## 功能概览

### 🧭 导航栏右键菜单

在侧边栏的**分组（Groups）**上右键点击，可以：

- **编辑分组** - 修改分组名称和颜色
- **复制分组** - 创建分组副本
- **导出分组** - 导出该分组的所有素材
- **分组统计** - 查看素材数量和存储占用
- **删除分组** - 删除分组（素材保留）

### 🎨 素材卡片右键菜单

在素材卡片上右键点击，可以：

#### 基础操作
- **在查看器中打开** - 进入专用大图查看模式
- **在 Finder 中显示** - 定位到文件位置
- **复制路径** - 复制文件的绝对路径

#### 素材管理
- **添加到收藏 / 取消收藏** - 快速切换收藏状态
- **移动到分组** - 快速移动到其他分组（带子菜单）
- **查看版本历史** - 打开检视器查看版本树

#### 创作相关
- **复制提示词** - 复制生成时使用的 Prompt

#### 导出与删除
- **导出素材** - 导出单个素材及其元数据
- **归档素材** - 移至归档区（不显示在主库中）
- **删除素材** - 永久删除（带二次确认）

### 📋 空白区域右键菜单

在素材网格的空白处右键点击，可以：

- **导入素材** - 打开导入对话框
- **从剪贴板粘贴** - 从剪贴板导入图片
- **刷新素材库** - 重新加载素材列表
- **全选** - 选中所有素材

## 交互设计特性

### 视觉风格
- 跟随系统主题（浅色/深色模式）
- 使用 MOSA V2 设计令牌
- 圆角卡片风格（12px 圆角）
- 浮动阴影效果

### 键盘导航
- **方向键上/下** - 在菜单项间移动
- **方向键右** - 打开子菜单
- **方向键左** - 关闭子菜单返回父菜单
- **Enter** - 执行当前菜单项
- **Escape** - 关闭菜单

### 智能定位
- 自动检测屏幕边缘，避免溢出
- 子菜单优先向右展开，空间不足时向左
- 垂直方向自动调整位置

### 状态反馈
- 禁用项显示为灰色
- 危险操作（删除/归档）显示为红色
- 操作完成后显示 Toast 通知
- 危险操作需要二次确认

## 技术实现

### 文件结构
```
app/
├── context-menu.mjs           # 通用右键菜单组件
├── context-menu-actions.mjs   # 菜单项定义和动作处理
├── app.mjs                     # 主应用集成
├── styles.css                  # 右键菜单样式
└── i18n.mjs                    # 国际化文本
```

### 核心模块

#### `context-menu.mjs`
- 创建和显示右键菜单
- 处理键盘导航
- 智能定位和边界检测
- 子菜单支持

#### `context-menu-actions.mjs`
- 定义所有菜单项
- 处理菜单动作
- 集成 API 调用
- 错误处理和反馈

### API 集成
所有菜单操作通过现有的 MOSA API 实现：
- `/api/assets/:projectId/:assetId` - 更新素材
- `/api/groups` - 管理分组
- `/api/open-folder` - 打开文件夹

### 国际化支持
完整的中英文双语支持：
- 简体中文（zh）
- 英文（en）

## 使用示例

### 快速收藏素材
1. 在素材卡片上右键点击
2. 选择"添加到收藏"
3. Toast 提示"已添加到收藏"

### 批量移动到分组
1. 在素材卡片上右键点击
2. 悬停"移动到分组"打开子菜单
3. 选择目标分组
4. Toast 提示"已移动到分组"

### 删除分组
1. 在侧边栏分组上右键点击
2. 选择"删除分组"
3. 确认对话框中点击"删除"
4. 分组被删除，素材保留
